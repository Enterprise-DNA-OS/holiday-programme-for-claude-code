# The office work without another front end

Bookings, session planning, family balances, staffing evidence and incident follow-up can run through a database and a trusted office operator. Recurring commands read the same records, and printed attendance and emergency sheets go to the programme floor.

This base has no parent self-service booking, mobile kiosk, offline sign-in, push notifications, photograph capture or per-staff access control. A static HTML dashboard is a read-only snapshot, not a shared live register. Regenerate and secure it after changes. Someone must enter the actual attendance from the programme's verified records.

Do not use a coding agent as the only means of locating or supervising a child. Maintain the programme's operational attendance and emergency procedures. For concurrent front-desk or parent access, Enterprise DNA scopes and builds the appropriate interface, permissions and audit trail around your database. Payment processing and government subsidy claims remain separate services.

The base is useful to trusted programme administrators without a front end. It is not a drop-in parent booking service. Omni by Enterprise DNA installs and runs the version your staff need.
